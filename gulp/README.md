# Веб-проєкт з автоматизацією на Gulp

Проєкт створено для автоматизації рутинних задач фронтенд-розробки за допомогою інструменту **Gulp**. Конфігурація базується на сучасному синтаксисі ES6 (`import/export`) та забезпечує повний цикл обробки HTML та SCSS.

## 🚀 Функціонал збірки

Налаштований конфігураційний файл `gulpfile.js` підтримує наступні можливості:

- **Робота з препроцесором SCSS:** Автоматична компіляція файлів `.scss` у стандартний CSS за допомогою `dart-sass`.
- **Стайлінг базового коду:** Форматування скомпільованого CSS-коду у розгорнутий, зручний для читання вигляд (`outputStyle: 'expanded'`).
- **Вендорні префікси:** Автоматичне додавання префіксів (`-webkit-`, `-moz-` тощо) через `gulp-autoprefixer` для забезпечення кросбраузерності (підтримка останніх 5 версій браузерів).
- **Мінімізація стилів:** Оптимізація та стиснення CSS-коду (видалення зайвих пробілів, коментарів) за допомогою `gulp-clean-css` та збереження у файл з суфіксом `.min.css`.
- **Оновлення сторінки в реальному часі:** Живий сервер на базі `browser-sync`, який миттєво відображає зміни в браузері при редагуванні HTML або SCSS коду без ручного перезавантаження.

## 📂 Структура проєкту

Для коректної роботи збірки файли та папки розташовані за такою схемою:

```text
gulp/
├── dist/                 # Тека готової збірки (генерується автоматично)
│   ├── css/
│   │   ├── index.css     # Відформатований CSS із префіксами
│   │   └── index.min.css # Мініфікований CSS для продакшну
│   └── index.html        # Скопійований HTML-файл
├── node_modules/         # Залежності проєкту (встановлюються через npm)
├── src/                  # Вихідні файли для розробки
│   ├── scss/
│   │   └── index.scss    # Головний файл стилів препроцесора
│   └── index.html        # Головна сторінка
├── gulpfile.js           # Конфігураційний файл Gulp
├── package.json          # Файл конфігурації npm та залежностей
├── package-lock.json     # Фіксація версій встановлених пакетів
└── README.md             # Інструкція до проєкту
```

## Інсталювання GULP

- npm install gulp sass gulp-sass browser-sync gulp-autoprefixer gulp-clean-css gulp-rename --save-dev
