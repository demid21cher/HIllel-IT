# Multi-functional Web Server (Express + Socket.IO)

Цей проект є веб-сервером на Node.js, побудованим із використанням **Express** та **Socket.IO**. Він підтримує віддачу статичних сторінок, обробку POST-запитів із валідацією та санітизацією даних, обробку HTTP-помилок, а також двосторонній обмін повідомленнями в реальному часі.

---

## 🚀 Функціонал

- **Маршрутизація (Express Routes):** Віддача HTML-сторінок (`/`, `/about`, `/contact`).
- **Чат у реальному часі (Socket.IO):** Передача повідомлень між клієнтами без перезавантаження сторінки.
- **Безпека та Валідація:**
  - Захист від XSS за допомогою функцій санітизації символів (`<`, `>`, `&` тощо).
  - Перевірка обов'язкових полів у POST-запитах.
  - Обмеження розміру тіла запиту до **80 байт** (`limit: '80b'`).
  - Встановлення безпечних HTTP-заголовків (`X-Content-Type-Options: nosniff`, `Content-Type: text/html; charset=utf-8`).
- **Обробка помилок:**
  - **400 Bad Request** — при відсутності обов'язкових полів у POST-запиті.
  - **404 Not Found** — кастомна HTML-сторінка для неіснуючих маршрутів.
  - **413 Payload Too Large** — при перевищенні ліміту розміру даних у 80 байт.
  - **500 Internal Server Error** — глобальний перехоплювач непередбачуваних помилок сервера.

## 📁 Структура проекту

```text
├── views/
│   ├── index.html       # Головна сторінка (із чатом Socket.IO)
│   ├── about.html       # Сторінка "Про нас"
│   ├── contact.html     # Сторінка "Контакти"
│   ├── 404.html         # Сторінка помилки 404
│   └── 500.html         # Сторінка помилки 500
├── public/              # Статичні файли (CSS, JS, картинки)
├── main_4.js            # Основний файл сервера
└── package.json
```
