## Короткий опис проекту

Даний проєкт створений за допомогою React та Vite.

### Основні можливості

- Функціональні компоненти
- Класові компоненти
- Використання props
- Використання useState

## Встановлення та запуск

1. Клонувати репозиторій:

```bash
git clone https://github.com/demid21cher/HIllel-IT/tree/master/React/my-react-app_2
```

2. Встановити залежності:

```bash
npm install
```

3. Запустити проєкт:

```bash
npm run dev
```
