## Data Fetching with Axios (`DataFetcher`)

У директорії `src/components` розроблено компонент `DataFetcher.jsx`, який реалізує асинхронне отримання даних за допомогою бібліотеки `axios`.

- **Ініціалізація запиту:** Запит до сервера виконується при першому завантаженні компонента за допомогою хука `useEffect` із порожнім масивом залежностей.
- **Асинхронна логіка (`async/await`):** Усередині `useEffect` оголошено та викликано асинхронну функцію, яка обробляє мережевий запит через `axios.get()`.
- **Відображення даних:** Отримані дані (наприклад, список постів або інформація про користувача) зберігаються в локальному стані та відображаються в інтерфейсі компонента.
- **Комплексна обробка станів:**
  - **Завантаження (`Loading`):** Доки запит триває, у компоненті відображається текстове повідомлення про процес завантаження (наприклад, "Завантаження даних...").
  - **Успішне виконання:** При отриманні відповіді від сервера дані оновлюються у стані, а індикатор завантаження вимикається.
  - **Обробка помилок (`Error`):** Блок `try/catch` перехоплює можливі мережеві помилки або відмови сервера, зберігає текст помилки в стан та виводить відповідне повідомлення користувачеві.
