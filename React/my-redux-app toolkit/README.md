# My Redux Toolkit App

## Додано асинхронну обробку даних

У проекті реалізовано роботу з асинхронними запитами за допомогою **createAsyncThunk**:

1. **Асинхронні дії (`cartSlice.js`)**:

   - Створено `fetchProducts` для отримання списку товарів з зовнішнього джерела.
   - Додано `extraReducers` для обробки життєвого циклу запиту:
     - `pending`: встановлює статус завантаження.
     - `fulfilled`: оновлює стан даними з сервера.
     - `rejected`: зберігає повідомлення про помилку в стані.

2. **Інтеграція в компоненти**:
   - У `ProductList.jsx` додано хук `useEffect` для автоматичного виклику `fetchProducts` при старті застосунку.
   - Компоненти тепер динамічно реагують на стани `loading` та `failed`, покращуючи UX.
