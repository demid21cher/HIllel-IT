# My Redux App

Цей проєкт є навчальним веб-додатком, розробленим з використанням **React** та **Redux Toolkit** для керування глобальним станом кошика покупок.

## Що було зроблено:

1. **Налаштування структури Redux (`src/redux`)**:

   - Створено файл `store.js` для ініціалізації глобального сховища за допомогою `configureStore`.
   - Створено слайс `cartSlice.js` із використанням `createSlice`, який містить початковий стан кошика, редюсери для додавання (`addToCart`) та видалення (`removeFromCart`) товарів, а також відповідні селектори.

2. **Інтеграція з React**:

   - У головній точці входу (`main.jsx`) додано компонент `Provider` із бібліотеки `react-redux`, який забезпечує доступ до Redux store для всього дерева компонентів.

3. **Рефакторинг компонентів**:
   - Підключено хуки `useSelector` та `useDispatch` у компонентах (`Cart.jsx`, `ProductList.jsx` тощо) для читання даних зі стору та відправки дій зміни стану замість використання локального стану.
