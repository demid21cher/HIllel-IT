# React UserProfile Component & Testing

У цьому розділі описано реалізацію компонента для асинхронного завантаження даних користувача з API (`UserProfile.jsx`) та написання юніт-тестів для перевірки його життєвого циклу (`UserProfile.test.jsx`).

## Що було зроблено:

1. **Створення компонента (`src/components/UserProfile.jsx`)**:

   - Реалізовано компонент, який виконує асинхронний `GET`-запит до API (`https://jsonplaceholder.typicode.com/users/1`) за допомогою `fetch` під час монтування.
   - Додано обробку трьох можливих станів компонента:
     - **Завантаження**: відображення індикатора (наприклад, "Завантаження...") під час виконання запиту.
     - **Успіх**: коректне виведення отриманих даних користувача (ім'я, електронна пошта тощо).
     - **Помилка**: показ повідомлення про помилку у разі невдалого виконання запиту.

2. **Тестування асинхронного запиту (`src/components/UserProfile.test.jsx`)**:

   - Налаштовано середовище тестування з використанням `@testing-library/react` для рендерингу та перевірки DOM-елементів.
   - Написано тести, які перевіряють:
     - Появу індикатора завантаження в початковий момент часу.
     - Відображення даних користувача після успішного завершення запиту.
     - Коректний вивід повідомлення про помилку у випадку збою мережі або сервера.

3. **Мокування API**:
   - Використано інструменти мокування (наприклад, `vi.mock` або `jest.fn`) для імітації відповідей від сервера (`fetch`), завдяки чому тести є ізольованими, стабільними та не залежать від зовнішнього інтернет-сервісу.
   - Протестовано всі ключові сценарії поведінки програми (стан очікування, успішний та неуспішний результат).
