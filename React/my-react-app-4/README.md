## Async Data with `use()` Hook (`MessageComponent`)

У директорії `src/components` розроблено компонент `MessageComponent.jsx`, який демонструє сучасний підхід до роботи з асинхронними даними в React за допомогою хука `use()`.

- **Симуляція асинхронного запиту:** Створено функцію, яка повертає `Promise` із штучною затримкою за допомогою `setTimeout` для імітації мережевого запиту до сервера.
- **Отримання даних через `use()`:** Замість традиційної комбінації `useEffect` та `useState` використання хука `use()` дозволяє зчитувати значення безпосередньо з `Promise` прямо під час рендеру компонента.
- **Відображення даних:** Отримане з `Promise` повідомлення відображається безпосередньо в розмітці компонента.
- **Обробка асинхронного стану:** Компонент розрахований на інтеграцію з `<Suspense>` на рівні вищого компонента (або батьківського елемента) для відображення резервного інтерфейсу (fallback) під час очікування завершення `Promise`.
