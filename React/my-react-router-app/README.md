## Routing & Navigation (`React Router`)

Реалізовано багатосторінкову навігацію в додатку за допомогою бібліотеки `React Router`.

- **Створення сторінок:** У директорії `src/components` розроблено три окремі компоненти-сторінки:
  - `Home.jsx` — головна сторінка додатку.
  - `About.jsx` — сторінка з інформацією про проєкт/компанію.
  - `Contact.jsx` — сторінка з контактними даними.
- **Налаштування маршрутів (`App.jsx`):**
  - Додаток огорнуто в `BrowserRouter` для включення підтримки маршрутизації.
  - За допомогою компонентів `Routes` та `Route` налаштовано відповідність між URL-шляхами та компонентами (`/` → `Home`, `/about` → `About`, `/contact` → `Contact`).
- **Навігаційне меню та стилізація:**
  - Для створення переходів між сторінками використано `NavLink` замість стандартного `Link`.
  - Налаштовано динамічне виділення активного посилання (за допомогою CSS-класу або inline-стилів), що дозволяє користувачеві бачити, на якій саме сторінці він зараз перебуває.
