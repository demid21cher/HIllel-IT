# React Form App

Цей проєкт містить реалізацію форми реєстрації з використанням бібліотек **Formik** та **Yup** для валідації даних без залучення глобального менеджера станy.

## Що було зроблено:

1. **Створення компонента форми (`src/components/Form.jsx`)**:

   - Розроблено форму з трьома обов'язковими полями вводу: **Ім'я**, **Електронна пошта** та **Пароль**.
   - Використано компоненти `Formik`, `Field` та `ErrorMessage` для зручного керування станом інпутів.

2. **Валідація даних за допомогою Yup**:

   - Створено схему валідації (`validationSchema`) для перевірки полів на заповненість (`required`).
   - Налаштовано перевірку правильного формату електронної пошти (`email`) та обмеження на мінімальну довжину для імені та пароля.
   - Забезпечено динамічне виведення текстових повідомлень про помилки під відповідними полями вводу в разі невідповідності правилам.

3. **Обробка подій форми**:
   - Реалізовано обробник сабміту (`onSubmit`), який виконується лише після успішного проходження валідації.
   - Додано очищення форми після успішної відправки даних.
