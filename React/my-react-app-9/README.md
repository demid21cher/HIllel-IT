# React Memoization Performance App

Цей проєкт демонструє використання інструментів мемоізації в **React** (`useMemo`, `useCallback`, та `React.memo`) для оптимізації продуктивності функціональних компонентів і запобігання зайвим ререндерам.

## Що було зроблено:

1. **Створення компонентів з мемоізацією**:

   - Розроблено структуру компонентів, що демонструють практичне застосування мемоізації під час роботи зі складними списками та обчисленнями.
   - Використано компонент вищого порядку `React.memo` для обгортання дочірніх компонентів з метою уникнення їхнього повторного рендерингу, якщо пропси не змінилися.

2. **Мемоізація обчислюваних даних (`useMemo`)**:

   - Застосовано хук `useMemo` для кешування результатів ресурсомістких обчислень (наприклад, фільтрації та сортування великих масивів даних).
   - Забезпечено, що перерахунок даних відбувається виключно при зміні ключових залежностей, уникаючи зайвих витрат ресурсів під час інших оновлень компонента.

3. **Мемоізація колбек-функцій (`useCallback`)**:

   - Використано хук `useCallback` для стабілізації посилань на функції-обробники подій, що передаються в якості пропсів до дочірніх компонентів.
   - Мінімізовано небажані ререндери дочірніх елементів, спричинені створенням нових екземплярів функцій при кожному повному оновленні батьківського компонента.

4. **Демонстрація ефекту мемоізації**:
   - Додано приклади та коментарі, що наочно ілюструють різницю в продуктивності до та після застосування механізмів мемоізації.
   - Забезпечено чистоту, читабельність та детальне коментування коду відповідно до технічних вимог завдання.
