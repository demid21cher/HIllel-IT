## Global State Management with React Context (`AppContext`)

Реалізовано передачу даних через дерево компонентів без використання "prop drilling" за допомогою `React Context API`.

- **Створення контексту:**
  - У директорії `src/context` створено файл `AppContext.jsx`.
  - Ініціалізовано контекст за допомогою `createContext()` із базовими значеннями за замовчуванням.
- **Реалізація Провайдера (`AppProvider`):**
  - Створено компонент-провайдер, який обгортає дочірні елементи (`children`) та передає їм значення контексту (наприклад, стан теми, список користувачів або мовні налаштування).
  - У Провайдері збережено локальний стан для можливості динамічного оновлення даних.
- **Обгортання додатку:** Головну структуру додатку обгорнуто в компонент Провайдера, забезпечуючи доступ до глобальних даних для всіх вкладених компонентів.
- **Споживання контексту (`useContext`):**
  - На глибоких рівнях вкладеності (2–3 рівні від кореня) використано хук `useContext` для безпосереднього отримання даних із контексту.
  - Продемонстровано відсутність потреби передавати пропси через проміжні компоненти, що спрощує архітектуру та підтримку коду.
