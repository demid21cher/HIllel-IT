# React Components: Controlled, Uncontrolled & Data Fetching

У цьому проєкті реалізовано основні підходи до роботи з формами та асинхронними запитами в React відповідно до поставлених завдань.

---

## 1. Controlled Component (`ControlledComponent`)

Розроблено контрольований компонент форми, де стан всіх елементів вводу повністю управляється через React.

- **Управління станом:** Використано хук `useState` для збереження та оновлення поточних значень елементів форми.
- **Елементи форми:** Включено текстове поле для введення даних та чекбокс.
- **Синхронізація:** Кожна зміна значення обробляється через події `onChange`, роблячи стан React єдиним джерелом правди (Single Source of Truth).
- **Відправка форми:** Обробник `onSubmit` скасовує стандартну поведінку браузера та отримує актуальні значення безпосередньо зі стану компонента.

---

## 2. Uncontrolled Component (`UncontrolledComponent`)

Розроблено неконтрольований компонент форми, де значення елементів вводу зберігаються та обробляються безпосередньо в DOM.

- **Використання референсів:** Для доступу до елемента вводу використано хук `useRef` замість створення локального стану (`useState`).
- **Отримання даних:** Значення зчитується безпосередньо з DOM-вузла (`ref.current.value`) лише в момент відправки форми.
- **Оптимізація:** Відсутність повторних рендерів компонента при кожному введені символу користувачем.

---

## 3. Запит до сервера (`HukUseEffect`)

Реалізовано компонент для отримання та відображення даних із зовнішнього сервера під час завантаження сторінки.

- **Побічні ефекти:** Запит виконується всередині хука `useEffect` при монтуванні компонента (із порожнім масивом залежностей).
- **Обробка станів завантаження:**
  - **Завантаження (`Loading`):** Індикація процесу отримання даних до завершення запиту.
  - **Успіх (`Success`):** Збереження отриманих даних у стан та їх відображення в інтерфейсі.
  - **Помилка (`Error`):** Перехоплення можливих мережевих помилок або відповідей із помилковим статусом та відображення відповідного повідомлення користувачеві.
